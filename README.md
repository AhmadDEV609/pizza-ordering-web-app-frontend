# 📌 Project Description

This project is a responsive and modern pizza ordering web application frontend built with React.js. The application includes multiple pages such as Home, Product Details, Cart, Checkout, Login, and Signup.

The main purpose of this project is to practice advanced frontend development concepts including state management, routing, reusable component architecture, and responsive UI design.

This project is designed for portfolio and learning purposes.
